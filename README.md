# Flowdesk — IT Help Desk

ต้นแบบ IT Help Desk ภาษาไทย มี Dashboard, Ticket, คิวงานส่วนตัว, คลังความรู้, รายงาน CSV และตั้งค่าโปรไฟล์

## Run

npm install
npm run dev

## Build

npm run build

## Prototype scope

ข้อมูลตัวอย่างและคำร้องที่สร้างบันทึกด้วย localStorage แยกตามเบราว์เซอร์ ไม่มีฐานข้อมูลส่วนกลาง การยืนยันตัวตน สิทธิ์ผู้ใช้ SLA หรืออีเมลจริง ข้อมูลทดสอบใช้ชื่อสมมติ รองรับมือถือและ prefers-reduced-motion
